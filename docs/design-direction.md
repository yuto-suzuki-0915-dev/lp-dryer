# Background Design System

## 基本方針

LP全体の背景は、各セクションごとに個別の装飾を作るのではなく、
ブランドカラーを基調とした少数の背景パターンを使い分ける。

背景の基本構成は以下の2色 × 濃淡2段階の4パターンとする。

1. 淡いアクア
2. 濃いアクア
3. 淡いアイボリー / シャンパンベージュ
4. 濃いシャンパンベージュ

各セクションでグラデーションを繰り返すことは避け、
単色に近い大きな色面を基本とする。

背景の切り替えによってページ全体にリズムを作り、
セクションの役割やストーリーの変化を視覚的にも伝える。

---

## 背景遷移の判断基準

背景色は機械的に交互に配置するのではなく、
セクション間のストーリー上の関係を基準に決定する。

### 1. ストーリーが大きく転換するとき

色相を変更する。

例：

PROBLEM → SOLUTION

問題提起から解決へ移るため、

寒色系 → 暖色系

のように明確な変化を与える。

### 2. 同じ内容を深掘りするとき

色相よりも濃淡を変える。

例：

SOLUTION → REASON

解決策の提示から、その根拠・性能の説明へ移るため、
背景を濃くして情報の密度と信頼感を高める。

### 3. 情報量の多いセクションの後

明るい背景に戻し、視覚的な休息を作る。

例：

REASON → GUARANTEE

性能説明による情報密度の高い状態から、
安心感や購入への不安解消へ切り替える。

## 現時点でのセクション背景案

| Section | Background | Role |
| --- | --- | --- |
| FV | 商品写真を中心とした水色・白・暖色 | 理想・憧れ |
| PROBLEM | 淡いアクア | 問題提起・静かな共感 |
| SOLUTION | 淡いアイボリー / シャンパンベージュ | 解放・解決策の提示 |
| REASON | 濃いアクア | 性能・根拠・信頼 |
| GUARANTEE | 淡いアイボリー / ベージュ | 安心・余白 |
| FINAL | 濃色（アクアまたはシャンパン系） | クロージング・購入への収束 |

FINALについては、
濃いアクアと濃いシャンパン系の両案を実装段階で比較して決定する。

---

## 背景装飾のルール

淡い白系 / アイボリー系の背景では、
背景が単調にならないように巨大な英字などを
非常に低いコントラストで配置することがある。

例：

- AIRFOLD
- ELNORA
- TRAVEL

これらは情報として読ませるものではなく、
背景を構成するグラフィック要素として扱う。

一方、アクア系背景では色面そのものを活かし、
巨大文字や装飾を過剰に追加しない。

背景はコンテンツより目立たせず、
写真・コピー・商品の視覚的優先順位を邪魔しない。
