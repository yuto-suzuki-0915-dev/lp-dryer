## Product overview

- **商品名**：AIRFOLD DUO
- **ブランド名**：ELNORA
- **商品カテゴリ**：旅行・出張向け折りたたみ式コンパクトドライヤー
- **一言で何の商品か**：日常のヘアケアを旅先へ持ち運ぶためのドライヤー

## Target & use case

- **主なターゲット**：旅先で使うドライヤーに不満を持っている女性・全年齢
- **使用シーン**：旅行、出張などの外出先。日本国内での使用を前提とする。
- **特に向いている人**：
  - ホテルの備え付けドライヤーの質や乾燥時間に不満がある人
  - 旅先でも普段に近い髪の仕上がりを維持したい人
  - 普段のドライヤーは大きく、旅行荷物へ入れにくいと感じる人
  - 一般的な折りたたみドライヤーの性能に不安がある人

## Customer problem & value proposition

### Customer problem

- 旅先の備え付けドライヤーでは、乾くまで時間がかかると感じる。
- 旅先のドライヤーでは、髪の乾燥・仕上がりに不満が残る。
- 普段のドライヤーを持参すると、旅行荷物へ入れにくい。
- 一般的な折りたたみドライヤーには、性能面で不安がある。

### Existing alternatives

- **ホテル備え付け**：機種や状態が滞在先ごとに異なり、使用感を事前に選べない。
- **普段のドライヤーを持参**：大きく、旅行荷物へ入れにくい。
- **一般的な折りたたみドライヤー**：性能に対する不安がある。

### Value proposition

- **解消する葛藤**：旅先で「髪の仕上がりを妥協するか、普段のドライヤーを荷物にするか」を選ばなければならない状況。
- **提供する価値**：荷物の軽さも髪の仕上がりもあきらめず、日常のヘアケアを旅先へ持っていけること。

## Differentiation

- **ホテル備え付けとの違い**：滞在先ごとに異なる機種ではなく、自分の一台を持ち運んで使える。
- **普段のドライヤーを持参する場合との違い**：折りたたみ構造により旅行荷物へ収めやすい。
- **一般的な折りたたみドライヤーとの違いとして伝えられる設計**：携帯性だけでなく、風量と温度管理も主要機能として備える。
- **商品コンセプト上の選択理由**：持ち運びやすさと、旅先でのヘアケアを一台で両立する。
- **比較訴求上の制限**：競合製品より高性能、最軽量、最速、No.1などの比較優位は確認されていないため訴求しない。

## Claims & evidence

### 確認済み

- 折りたたみ状態と展開状態を持つ商品外観がある。
- 折りたたみ時の本体寸法は151×63×48mm。
- 定格消費電力は1,200W、最大風量は1.8m³/分。
- 折りたたみ設計、風量、温度管理、髪の乾燥、衣類乾燥が商品機能として設定されている。
- 日本国内での使用を前提とする。
- 商品条件として「1年間完全保証」を設ける。
- 保証期間は購入日から1年間。通常使用で生じた自然故障を対象に、無償修理または同等品への交換を行う。
- 保証の利用には購入証明が必要。落下、水濡れ、誤使用、改造、通常損耗は対象外。
- 確認済みの数値として、折りたたみ時寸法、定格消費電力、最大風量、保証期間を使用できる。

### 未確認

- 重量
- 温度・温度制御方式
- 乾燥時間
- 対応電圧・海外対応
- 衣類乾燥アタッチメントの形状、使用方法、安全条件

### 現時点で存在しない根拠

- 客観的な性能データ
- 比較試験
- 販売実績
- 受賞歴
- 第三者評価

## Core messaging

商品価値を表す核として、以下の表現を維持する。

- 日常のヘアケアを旅先へ持ち運ぶ
- 荷物の軽さも、髪の仕上がりも、あきらめない
- 持ち運べる一台

> Main Copy、CTA、Section固有の機能表現など、LP上での具体的なCopyは `docs/lp-structure.md` で管理する。

## Constraints

- 根拠のない最上級表現を使わない。
- 競合製品やホテル備え付けドライヤーを一律に低性能と断定しない。
- `最軽量`、`最小`、`最速`、`ダメージゼロ`、`必ずまとまる`、`No.1`を使わない。
- 架空の実験値、受賞歴、販売実績、満足度を追加しない。
- 未確認の重量、展開時寸法、温度、乾燥時間を掲載しない。
- 価格、送料、割引はLP本体に掲載せず、外部購入サイト側で扱う。
- 1年間完全保証は、確認済みの対象範囲と除外条件を併記する。
- 衣類乾燥の具体的な使用方法・アタッチメント・安全条件は、確認済みの情報に基づいて説明し、未確認の内容を推測で補わない。
- 商品本体の形状を変更して見せない。
