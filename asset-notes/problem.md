# PROBLEM

## 素材

### `public/images/problem/problem_a_hotel_dryer_v02.png`

- ホテルの備え付けドライヤーを使う女性の場面。
- 単なる設備写真ではなく、短いコードの範囲に合わせて設備側へ身体を寄せ、不便を感じている使用体験を表す。
- 大げさな困り顔、時計、説明アイコンによる演出は含めない。

### `public/images/problem/problem_b_packing_conflict_v02.png`

- ほぼ埋まった旅行荷物と、普段のドライヤーが収まりにくい場面。
- 「いつもの仕上がりを守りたいが、持っていくと荷物になる」という葛藤を表す。

## 固定事項

- 見出し：`旅先の髪、こんなお悩みは？`
- 対立をまとめるコピー：`仕上がりか、荷物か。`
- 画像内コピー：
  - `備え付けでは、仕上がりが気になる。`
  - `持っていけば、荷物になる。`
- 採用構図：A SHORT。
- 写真面の高さ：375px幅表示時に210px。
