# Reference notes

`references/images/` 内の参考画像について、何を参考にするかをSection別に記録します。
`asset-notes/` が使用素材の説明を扱うのに対し、ここでは参考デザインの参照意図を扱います。

## Files

- `fv.md`：ファーストビュー
- `problem.md`：PROBLEM
- `solution.md`：SOLUTION
- `reason.md`：REASON
- `final-cta.md`：GUARANTEE / CTA
- `shared.md`：複数Sectionで共通して参照する画像

## Writing notes

参考画像を追加した時点で、該当ファイルに必要な内容だけを書きます。未使用のファイルは空のままで構いません。

- 画像パス：対象を特定できる `references/images/` 内のパス
- 出典：分かる場合のみ元ページのURLなど
- 参照意図：何を検討するための参考か
- 取り入れたい点：Layout、Typography、Color、画像の扱いなど
- 取り入れない点・制約：そのまま使わない要素や避ける表現

参考画像のCopy・商品情報・デザイン全体を、自動的に採用済みとは扱いません。
参考画像はProduction assetとして直接使用しません。
Project全体で確定したReference方針は `docs/references.md`、Design方針は `docs/design-direction.md` で管理します。
